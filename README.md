# Cybersecurity Asset Triage with Python

This repository contains a cybersecurity-focused Jupyter notebook created as part of the Per Scholas AI + Jupyter + GitHub Lab.

## Project Overview

The notebook uses Python to review a fictional inventory of computers and servers and identify assets that may require additional security attention.

The analysis checks:

- Patch age
- Encryption status
- Endpoint protection status
- Asset ownership

## Security

All device names and information used in this repository are fictional and intended only for training.

No passwords, API keys, access tokens, PII, PHI, real hostnames, or organizational data are included.

## Key Takeaway

This project demonstrates how a simple Python workflow can help automate repetitive cybersecurity analysis and document both the analysis process and its results.
